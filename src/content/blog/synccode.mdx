## 1. 给仓库加上“上游”

```bash
# fork仓库默认是有上游的，使用命令查看远程信息
git remote -v
```
可看到`origin`、`upstream`
若没有**upstream**则执行如下代码

```bash
git remote add upstream https://github.com/YYsuni/2025-blog-public.git
```
---

## 2. 拉取远程仓库代码，确保本地与远程仓库一致，防止冲突

```bash
git pull origin main
```
## 3. 抓取上游最新代码到本地

```bash
git fetch upstream
```

![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync1.webp)

## 4. 打开Git Graph插件
- **Merge into current branch**
![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync2.webp)
> 记得勾选 **`No Commit`**
![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync3.webp)

## 5. 解决冲突（仅限冲突时）

<Collapse title="图文流程">

1.  打开 VSCode 分支管理 查看存在冲突的文件。 
2. 找到类似下面的标记：

```json
采用当前更改|采用传入的更改|保留双方更改|比较变更
```

```json
...你原来的内容...
```



3. 把标记删掉，保留你想要的内容，**保存文件**。  
4. 解决冲突后，暂存文件，**`commit`** (点击继续）

![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync4.webp)
</Collapse>
---

## 6. 推送代码到 GitHub

<Collapse title="图文流程">

1. 右键 **`main`**

![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync5.webp)

2. Push Branch(推送到远程)

![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync6.webp)
![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync7.webp)

3. **`main | origin`** 即推送成功

![](https://img.131714.xyz/file/blog/Article/SyncUpstream/sync8.webp)
</Collapse>
